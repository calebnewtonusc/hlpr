# HLPR

HLPR matches people who need help with people who can give it, through the friends, family and church networks they already have. It started with LA wildfire relief.

You talk it through with an AI care coordinator, it works out what you need or what you can give, and it connects you with verified people, churches or organizations who can help.

Live at [hlpr-tawny.vercel.app](https://hlpr-tawny.vercel.app)

## Run it

```bash
npm install
cp .env.example .env.local
npm run dev
```
